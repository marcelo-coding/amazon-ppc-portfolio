Dev and Automation

AI Agents and MCP

Agents do the tireless reading work and I keep the accountable judgment, because the point of this system is to scale my attention rather than to replace it.

A Fleet of Amazon Ads MCP Servers

I run a fleet of Amazon Ads MCP servers with one server per seller account, which gives AI agents a clean and isolated connection to each account through the official Ads API. The one account per server rule is a deliberate safety boundary, because an agent that can only see one account can never confuse two clients' data, push a change to the wrong campaign, or leak one brand's numbers into another brand's report. Every capability the agents have flows through that same API surface, so there are no screen scrapers and no fragile browser scripts anywhere in the stack.

Agent Driven Audits and Reporting

With that plumbing in place, agents do the reading work that used to consume my week. An agent can sweep an entire account against my audit checklist, pull the reports, sort every target into performers, bloat, and bleeders, and hand me a written summary with the evidence attached, which turns an audit from a day of clicking into an hour of review. The same pattern powers reporting, where agents assemble the weekly numbers and the monthly actuals from live API data, so the reports that reach clients are built from the source rather than retyped from a dashboard.

Human Review Is the Contract

Every change an agent proposes passes through my review before it touches the account, because the point of this system is to scale my judgment rather than to replace it. Agents draft, and I approve, which means the accountability for every bid, budget, and negation stays with a person whose name is on the engagement. The automation that does write on a schedule runs as pinned deployments where every rule change is a version that can be promoted or rolled back deliberately, so even the autonomous parts of the system answer to a change history a human controls.

What This Produces

The outcome is coverage that manual work cannot match at a quality bar that pure automation cannot match, because agents never skip a campaign out of fatigue and I never approve a change without a reason attached. Audits happen more often, reports arrive on time against the same data the optimization used, and the account benefits from tireless reading paired with accountable judgment.
