How to Use This Email Signature

  1. Open this file in a web browser
  2. Select and copy the signature below (Ctrl+A inside the preview box, then Ctrl+C)
  3. In Gmail: Settings → See all settings → General → Signature → Paste
  4. In Outlook: Settings → Mail → Compose and reply → Email signature → Paste
  5. In Apple Mail: Preferences → Signatures → Create new → Paste
